
# Competitive Programming

A curated collection of essential code snippets, templates, and utility functions frequently used in competitive programming. This repository is designed to help you save time during contests and build a strong foundation of reusable components.

## 🚀 Features

- Commonly used algorithms and data structures
- Template code for quick contest setup
- Utility functions for math, strings, graphs, DP, etc.
- Clean, readable, and modular code


## 📌 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/competitive-programming.git
   ```

2. Copy the relevant code/template to your contest environment.

3. Modify as needed based on the problem.
